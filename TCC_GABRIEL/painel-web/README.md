# Painel do motorista

Dashboard React/Vite com autenticação de motorista, contagem diária de ida/volta, dispensa, reinício da demonstração e transmissão GPS.

```text
npm ci
npm run dev
```

Use VITE_API_URL com a origem do backend (sem /api). Login de demonstração: motorista / motorista123.

Validação: npm run build e npm run lint. Publicação: [DEPLOY_NUVEM.md](../DEPLOY_NUVEM.md).
